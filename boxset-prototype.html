About this prototype

This demo explores how Roon could support box sets as a top level browsing experience. Roon today handles multi-disc albums but has no concept of a collection of albums that makes box sets meaningful.

The five box sets here represent three structural models. May 1977 and Plugged Nickel are live archives grouped by set and night. The Beatles in Mono is a curated collection of discrete albums. Tim: Let It Bleed Edition is a single album presented as four distinct versions. The Hyperion Romantic Piano Concertos tries to extend the scheme into the classical genre. In each case the proposed hierarchy is the same: Box Set → Work → Disc → Track — using the existing GROUPING file tag as the signal for Roon to create a box set.

Dual Identity
The same album, two ways
Design Problem: Edition vs. Duplicate
Revolver exists both as a standalone album and as Disc 7 of The Beatles in Mono. A well-designed music app treats these as two editions of the same work — not duplicates. Both entries lead to the same track data, but carry different context in their breadcrumbs and queue metadata. Click either card to see how the track view differs. Roon's VERSION should enable this.
